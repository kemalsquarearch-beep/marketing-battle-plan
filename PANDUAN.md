# Cara online di Netlify
1. Ekstrak ZIP, upload seluruh isi folder ke repository GitHub baru.
2. Netlify > Add new project > Import from Git > pilih repository > Deploy.
3. Project configuration > Environment variables > tambah ADMIN_PASSWORD (password kuat).
4. Deploys > Trigger deploy.
5. Buka situs > klik Download > Setting Admin > isi WA, biaya, rekening, QRIS, disclaimer, persetujuan.

Catatan: drag-and-drop folder tidak menjalankan fitur pembayaran; gunakan Git.
